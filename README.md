## 📌 Project Overview

The **AI Career Guidance & Skill Recommendation Agent** is a Streamlit-based web application designed to help students, freshers, and job seekers identify suitable career paths based on their education, skills, interests, and experience.

This project aligns with **United Nations Sustainable Development Goal 8 (SDG 8)** by promoting employment readiness, skill development, and decent work opportunities through applied Artificial Intelligence.

---

## 🎯 Problem Statement

Many students and early-career professionals face challenges such as:
- Lack of proper career guidance
- Uncertainty about required skills for jobs
- Skill gaps between education and industry needs
- Limited access to personalized career counseling

These issues contribute to unemployment and underemployment.

---

## 🤖 Solution Description

This project provides an **AI-powered career guidance system** that:
- Accepts multiple skills across different streams
- Analyzes skill combinations using rule-based AI logic
- Recommends career domains and job roles
- Identifies skill gaps and learning paths
- Supports decision-making for career growth

## 🧭 AI Workflow

**Input → Processing → Output**

**Input:**
- Education / Stream
- Skills (multiple, comma-separated)
- Career interest
- Experience level

**Processing:**
- Skill classification and domain mapping
- Career path identification
- Skill gap analysis

**Output:**
- Recommended career paths
- Identified domains
- Skills to learn
- Learning platform suggestions
